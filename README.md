# Even or Odd
This program asks users to enter a whole number, where it will then determine if it is even or odd.

## How to Run
1. Open 'main.py'
2. Run the program
3. Enter num1/whole number

## Input Neeeded
- num1

## Sample Output
- Enter a whole number: 144
- 144 is even.
